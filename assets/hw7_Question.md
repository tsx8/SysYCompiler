# 竞速排序

## 问题描述

竞速排序作业共有八个测试程序，课程组将公开一个测试程序，其余七个测试程序不公开，八个测试程序成绩均计入总分。

一、请在之前作业的基础上，为编译器实现代码优化功能。输入输出及处理要求如下：

1. 将源文件（统一命名为 **testfile.txt**）编译生成MIPS汇编并输出到文件中（统一命名为 **mips.txt**
   ），具体要求包括：自行设计中间代码数据结构，再从中间代码生成MIPS汇编。请设计实现输出中间代码的有关函数，输出格式见
   **课程资料-编译技术实验中间代码输出格式说明**，优化前后的中间代码分别输出到命名为“*
   *testfilei\*学号\*姓名_优化前/后中间代码.txt**”的文件中；
2. 请设计为方便打开/关闭优化的模式，能方便提供优化前/后的目标代码，将优化前后的目标代码分别重命名为“*
   *testfilei\*学号\*姓名_优化前/后目标代码.txt**”的文件中（提交到竞速排序作业中的需为产生优化后目标代码的版本），并将公开测试程序
   testfile7 的上述4个文件打包为一个 **zip文件** 提交到 **2025优化前后中间代码目标代码提交** 作业；
3. 凡选择生成 MIPS 代码的同学，均需提交此项作业，**生成 PCODE和LLVM IR的同学请勿提交此项作业**;
4. 自行调试时，可使用MARS仿真器（**课程资料-编译专用Mars2025**
   ），提交到平台的编译器只需要能按统一的要求生成MIPS汇编代码文件即可，MARS仿真器及使用说明请下载平台中提供的最新版本。

二、优化的要求如下：

1.
代码生成时合理利用寄存器，包括全局寄存器和临时寄存器，建议使用规范的全局寄存器分配方法（例如引用计数或图着色算法）分配全局寄存器，使用临时寄存器池管理和分配临时寄存器。遵循MIPS的寄存器使用规范和调用规范，并能生成较高质量的目标代码；
2. 建议实现公共子表达式删除（GVN-GCM）优化；
3. 建议通过数据流分析（活跃变量分析或者到达定义分析）实现较复杂的全局优化，例如循环不变代码外提、死代码删除等。
4. 建议实现课堂上介绍过的某些典型优化，例如代码内联、常量传播、复制传播、窥孔优化等；
5. 优化最终评分依据以竞速排名结果为主，完成优化的数量、种类、生成代码质量等因素，仅作为辅助评分依据。

三、优化文章

提交优化文章到本次作业的相应题目中，以指导如何完成编译实验为主要内容，着重说明在优化中遇到的各个困难点及所采用的解决方案，要求内容具体，阐述清楚，题目和内容组织自定。注意，优化文章不做强制要求，但在总分里有对应的分值，
**不提交优化文章将无法得到相应的分值**！提交的优化文章将择优发布给下一届同学。

## 输入形式

testfile.txt为符合文法要求的测试程序，另外可能存在来自于标准输入的数据。

按如上要求将目标代码生成结果输出至mips.txt中，并输出优化前后的中间代码，中文字符的编码格式要求是UTF-8。

## 排行榜说明

1. 排行榜会记录并展示当前提交程序的 FinalCycle 以及个人历史的 FinalCycle，若该测试程序未通过则记为10100。
   **最终的评分以最后一次提交的结果为准。**
2. 根据每个程序的排序和不同的权值计算得到竞速排名的分数。
3. 点击表头可以根据该列进行排序。
4. 评测分数只是为了展示目标代码运行结果的正确性，不表示**竞速排序所得的分数**。
5. FinalCycle的计算公式为 FinalCycle = DIV * 15 + MULT * 5 + JUMP/BRANCH * 2 + MEM * 3 + OTHER * 1。

   在运行正确的前提下，FinalCycle越小排名越靠前。
